# Fotos propias

Sube aquí tus fotografías (solo fotos propias o con derechos comprobados).

## Cómo subirlas desde GitHub (sin instalar nada)

1. Abre esta carpeta en GitHub: `src/assets/fotos/`.
2. Pulsa **Add file → Upload files** y arrastra las fotos.
3. Abajo, en **Commit changes**, escribe qué subes (ej.: «Fotos tarta») y confirma.
4. Pide a Claude Code: «Pon las fotos nuevas de `src/assets/fotos/` en sus contenidos». Se encarga de enlazarlas, escribir el texto alternativo y quitar la imagen provisional.

## Formato

- **JPG** (o PNG). Nada de HEIC: en el iPhone, *Ajustes → Cámara → Formatos → Más compatible*, o expórtalas como JPG.
- **Mínimo 1600 px de ancho**, en horizontal. La web genera sola los tamaños pequeños y el formato WebP.
- Máximo unos **5 MB** por foto.
- Luz natural, sin filtros ni textos encima.

## Nombre del archivo

`<contenido>-<detalle>.jpg`, en minúsculas, con guiones, sin tildes ni espacios. Ejemplos:

- `tarta-de-galletas-de-nata-entera.jpg`
- `tarta-de-galletas-de-nata-porcion.jpg`
- `como-hacer-las-mejores-galletas-de-nata-masa.jpg`
- `portada.jpg` (foto principal de la portada)
- `autor.jpg` (opcional, para «Sobre el proyecto»)
